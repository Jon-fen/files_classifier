# Clasificador de Documentos PDF escaneados o como fotografía

Aplicación web para clasificar y renombrar PDFs administrativos usando IA (Anthropic Claude Haiku).

Funciona con documentos escaneados desde papel, mejores resultados escaneos limpios y en buena calidad. Escaneos escritos a mano el resultado es variable dependiendo que tan legible sea la letra.


https://filesclassifier-jonfen.streamlit.app/

🔒 Privacidad y datos: Esta herramienta usa la API comercial de Anthropic (no la versión de consumo). Según su política oficial: "By default, we will not use your inputs or outputs from our commercial products (e.g. Anthropic API) to train our models." — Anthropic Privacy Center
Los archivos se procesan solo en memoria y no se almacenan en ningún servidor propio. Solo se lee la primera página de cada PDF. Aun así, actúa siempre según las políticas de privacidad de tu organización.
